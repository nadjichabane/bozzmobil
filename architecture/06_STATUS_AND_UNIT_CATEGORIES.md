# 06 — BOZZMOBIL Status & Unit Categories

## SCHEMA UNIT

`SCHEMA UNIT` berarti **jenis/kategori unit**.

Allowed values:

| Value | Description |
|---|---|
| REGULER | Kategori unit Reguler |
| CARVIAN | Kategori unit Carvian |
| TRADE IN | Kategori unit Trade In |

Nilai lain tidak boleh dibuat tanpa perubahan business rule.

## Inspection result

Status yang terlihat pada flow:
- LULUS INSPEKSI
- REJECT / TOLAK

## Stock

Status yang terlihat pada flow:
- READY
- NOT READY

## QC

Status/proses yang terlihat:
- PROSES QC
- DONE QC

Daftar status rinci dapat ditambahkan ketika definisi operasional final tersedia.
